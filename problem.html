Common fixes

1. In Render → your backend service → Environment, set UTLT_AI_API_KEY to your Supabase AI API key (the value beginning with mle_).

2. Keep UTLT_AI_API_URL set to https://raujzsawwpmixwlcgcgs.supabase.co/functions/v1/public-ai-api.

3. Confirm the Render start command is uvicorn api:app --host 0.0.0.0 --port $PORT with the service root directory set to backend.

4. If the backend is sleeping, configure an external uptime monitor to request /health every 5 minutes. A watchdog thread cannot wake a completely sleeping Render service by itself.
